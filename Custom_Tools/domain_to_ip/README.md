# 🌐 Domain To IP Converter

A simple Python tool to convert domain names to IP addresses using socket programming.

## ✨ Features

- 🔍 **Domain to IP Lookup** - Fast DNS resolution
- 🎨 **Colorful Banner** - Eye-catching ASCII art display
- ⚡ **Lightweight** - No heavy dependencies
- 🛡️ **Error Handling** - Graceful error messages

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Python 3 | Core language |
| socket | DNS resolution |
| pyfiglet | ASCII art banner |
| termcolor | Colored terminal output |

## 🚀 Quick Start

### Prerequisites

- Python 3.x installed
- pip (Python package manager)

### Installation

```bash
# Clone the repository
git clone https://github.com/swoyon01/domain-to-ip-converter.git

# Navigate to project directory
cd domain-to-ip-converter

# Install dependencies
pip install -r requirements.txt

# Run the tool
python domain_to_ip.py
```
