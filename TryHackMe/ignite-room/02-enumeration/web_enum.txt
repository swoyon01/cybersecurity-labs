### CVE Details

| CVE | Description | Severity |
|-----|-------------|----------|
| CVE-2018-16763 | Remote Code Execution in FUEL CMS <= 1.4.1 | 9.8 Critical |

**Vulnerability:**
- Improper input validation in `/pages/select` filter parameter
- Improper input validation in `/preview` data parameter
- Allows PHP code injection and execution

**Affected Versions:** FUEL CMS <= 1.4.1

**Fixed In:** FUEL CMS 1.4.2
